## 🚀 Tentang Website

Website **GLOBEX SOLUTIONS** adalah platform profesional yang menyediakan layanan teknologi terintegrasi untuk kebutuhan bisnis dan akademik. Dibangun dengan teknologi modern dan desain responsif.

### ✨ Fitur Unggulan

| Kategori | Fitur |
|----------|-------|
| 🎨 **Desain** | Dark/Light Mode, Responsif, Animasi Smooth |
| 💼 **Layanan** | 6 Layanan Utama (Data Analysis, Software Dev, APK Java, Joki Coding, Website, Makalah Ilmiah) |
| 📊 **Statistik** | Live Counter Proyek, Klien, Publikasi |
| 📁 **Portfolio** | Galeri Proyek yang telah dikerjakan |
| 👥 **Team** | Profil Tim Ahli |
| 💰 **Harga** | Estimasi Biaya Transparan |
| 📝 **Blog** | Artikel Terbaru Seputar Teknologi |
| ❓ **FAQ** | 5 Pertanyaan Umum dengan Accordion |
| 📞 **Kontak** | Form Email & WhatsApp Floating Button |
| 🔒 **Keamanan** | Garansi Revisi, Privasi Data, Anti-Plagiarisme |
